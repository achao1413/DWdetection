# DW Detection v1.1.7 设计交付说明

> 用途：供产品、设计与前端研发对照实现。本文记录截至当前原型的页面、交互、状态与视觉规范；可运行效果以 `deliverables/DWdetection-v1.1.7-preview.html` 为准。

## 1. 产品目标与范围

目标用户是缺少算法经验的外部三方交付人员。产品通过页面内提示，帮助用户完成“上传数据集 → 标注 → 训练 → 部署 → 运行算法”，减少错标、漏标和训练返工。

v1.1.7 已覆盖：

- 样本上传与异常图片自动清理。
- 六维样本质量评估与行动建议。
- 标注教程示例与首次使用引导。
- 训前环境、系统依赖检查及异常行动提示。
- 训练、部署、验证的前端 Mock 闭环。
- 表计模板与验证入口，以及指针模板四步静态配置指引。

本版本不包含算法子类插拔复用、站间数据共享仓、训练经验参数固化和真实算法服务。

## 2. 信息架构

主导航固定为“推理 / 标注 / 训练”。表计模板相关页面从算法详情进入，不加入主导航。

```text
推理首页
  └─ 算法详情
      └─ 表计模板 & 验证
          └─ 指针模板配置
标注数据集
  └─ 标注工具
      ├─ 样本质量报告
      └─ 标注教程示例
训练列表
  ├─ 新建训练
  ├─ 训前自检
  └─ 部署 → 推理首页
```

## 3. DW 运营视觉规范

### 3.1 使用原则

- 页面主体保持安静、紧凑、适合反复操作和快速扫描。
- 毛玻璃用于弹窗、浮层、工具栏等有明确层级的区域；普通页面区块和表格不统一套磨砂外壳。
- 禁止在组件内随意硬编码颜色，优先使用 `src/design-tokens.ts` 或 Element Plus 语义变量。
- 业务图标使用 `@tabler/icons-vue`，不使用 Element Plus 图标作为业务图标。
- 卡片圆角不超过 8px，按钮组间距统一为 8px。

### 3.2 面板与弹窗

- DW 运营毛玻璃：半透明暗色填充、`backdrop-filter: blur(100px)`、8px 圆角。
- 标题下方和底部行动区上方不使用分割线。
- 确认弹窗宽度：400px。
- 模态弹窗：小号 480px、中号 600px、大号 800px。
- 除超大弹窗外，最大高度 600px；标题与行动区固定，内容区内部滚动。
- 关闭只使用右上角关闭图标，不重复提供“关闭”文字按钮。

### 3.3 页面与表格

- 顶部栏固定、全宽自适应，不使用固定页面宽度。
- 列表页表格不使用外包围卡片壳。
- 表头与内容共用列模板，横向滚动保持同步。
- 数据行使用交替底色区分，不使用行分割线。
- 页面不产生非预期纵向滚动；分页固定在内容底部，长列表在表格区域内部滚动。

## 4. 页面说明

### 4.1 推理首页 `#/`

- 左侧算法运行区自适应浏览器宽度，右侧“算力概览 / 在线训练”保持固定宽度。
- 算法卡片整个区域可点击进入详情；卡片仍保留明确的运行或停止操作。
- 部署完成后由弹窗引导回到此页运行新版本，不使用 Toast 代替流程确认。

### 4.2 算法详情 `#/algorithms/:id`

- 左上返回按钮回到推理首页。
- 保留快速检测和历史任务，快速检测不再在按钮左侧重复展示分析类型选择。
- 表计类算法保留“表计模板 & 验证”入口。
- 顶栏、底部分页固定，任务卡片区内部滚动，中间分隔线贯穿内容高度。

### 4.3 标注数据集 `#/annotation`

- 主操作为“导入数据”，不展示“批量训练”。
- 列：数据名称、分析类型、上传时间、描述、已标注/总图片数、样本质量评估、操作。
- 进度条右侧显示“已标注/总图片数”。质量标签显示“优秀 / 一般 / 待优化 / 暂不可评估”。
- 点击质量状态等同于查看详情，打开完整质量报告。
- 行内保留“详情 / 标注”，其余操作进入“更多”菜单。

#### 上传弹窗

- 使用小号模态弹窗 480px，支持图片、ZIP、DWD 选择；数据包文件名可作为数据集名称。
- 不在上传阶段弹出重复数据确认，也不执行文件名和分辨率自动规范。
- 损坏或无法解析的图片直接自动清理，上传后以模态弹窗展示处理文件清单。
- 图片列表独立滚动，底部行动区固定。

### 4.4 数据集质量报告

六个一级维度：

1. 样本数量。
2. 样本时间分布（上午 7:00-11:00、正午 11:00-14:00、下午 14:00-20:00）。
3. 样本重复度。
4. 类别均衡度。
5. 目标画幅占比。
6. 标注质量（标注完整性与标注规范性取短板）。

#### 等级与总评

- `excellent`：优秀。
- `normal`：一般。
- `poor`：界面文案“待优化”，避免对用户使用攻击性表达。
- `notReady`：暂不可评估。
- 六项均优秀为优秀；无待优化且非全优秀为一般；任一项待优化则总评待优化；标注数据不足则暂不可评估。

#### 展示规则

- 雷达图为六轴 SVG/CSS，不依赖图表库；优秀 100、一般 60、待优化 30、待评估不闭合。
- 左侧完整展示雷达图和数据集元信息；右侧“优先改善建议”固定标题，建议列表内部滚动。
- 一般、待优化、待评估项优先展开；优秀项默认收起。
- 建议文案保持短句，使用“AI诊断 / AI建议 / AI预警”层级表达。
- 每个问题右下角给出直接行动：添加图片、图片去重或进入标注。
- 标注完整性中，进度条与“已标注 x/y”同一行。

### 4.5 标注工具 `#/annotation/:datasetId`

- 顶部工具行 64px；左侧工具栏 44px；右侧标签配置 260px；其余空间给画布。
- 画布图片不加额外底色或外边距，底部缩略图列表保持可见。
- 顶部不持续暴露质量等级，仅展示次级“样本质量”按钮，点击打开报告。
- 工具栏底部单独放置“教程示例”按钮，与常用标注工具分组。

#### 标注教程示例

- 用户第一次选择某个分析类型时自动打开；每种分析类型只主动打开一次。
- 关闭首次教程后，以一次性 Popover 指向工具栏入口，提示可在此重新打开。
- 浮窗可在视口范围内拖动，可遮挡画布，关闭后不最小化。
- 正确/错误示例成对展示，支持左右切换多组示例。
- “查看完整说明”进入 Mock 说明页面。

### 4.6 训练列表与新建训练 `#/training`

- 顶部主按钮文案为“新建训练”。
- 表格列：算法名称、版本、分析类型、训练状态、完成时间、操作。
- 行操作保留部署和“更多”菜单，不直接展示诊断或去运行按钮。
- 训练算法只允许选择已部署算法；当前原型为电力检测算法。
- 选择框内的版本号、数据集质量标签位于下拉箭头左侧。
- 若已部署版本不是最新训练版本，在算法选择下方提示并提供部署最新版本入口。

### 4.7 训前自检

样本质量与自检解耦：自检仅读取当前 `qualityResult` 摘要，不重新计算六维数据。

#### 检查范围

- 运行环境：GPU 占用 >90%、磁盘可用空间 <5GB、内存占用 >90%、训练镜像异常。
- 系统依赖：标品算法包版本不兼容。
- 状态文案：通过、AI提醒、AI预警。

#### 放行规则

- 全通过：无感开始训练。
- 只有 AI 提醒：允许继续训练。
- 存在 AI 预警：训练按钮置灰，不提供一键处理，用户不可继续。
- 样本质量“待优化”只做高风险确认，不等同于环境阻塞。
- 样本质量“暂不可评估”且其余检查通过时，主按钮为“进入标注”。
- 自检条目只做简短提示，当前版本隐藏条目内修复按钮。

### 4.8 异常行动提示

异常提示按单个业务事件主动出现，不把所有异常集中展示。

- 上传异常：损坏或无法解析图片自动清理，随后展示结果清单。
- 验证未通过：提示成功率未达到验收阈值，提供查看漏检图片入口。
- 部署超过 10 分钟：提示部署超时，提供停止部署。
- 部署结束：短延时 Mock 交替成功或失败；成功使用模态弹窗引导去推理首页，失败提供清晰结果提示。

### 4.9 表计模板与验证 `#/meter-template-validation`

- 返回按钮回到来源算法详情。
- “新建表计模板 & 验证”进入指针模板配置页面。
- “开始验证”运行 Mock；验证失败时主动打开异常提示并引导查看漏检图片。

### 4.10 指针模板配置 `#/meter-template-configuration`

页面复刻线上工具结构：顶部操作栏、左侧画布、底部工具栏、右侧配置面板。

#### 四步指引

1. 表盘定位：展示预设表盘矩形框和锚点，说明覆盖指针活动范围和完整量程。
2. 指针轴心定位：在表盘框上增加中心点和细密放射辅助线。
3. 角度和量程配置：展示预设扇形、射线、锚点和多段量程内容。
4. 选择分析类型并完成：展示填写后的模板名称、指针类型和确定操作。

指引支持打开、关闭、上一步、下一步、跳过、退出和重新查看。步骤变化只切换 Mock 预设状态。

#### 工具栏与参考浮窗

- 工具顺序：底图、表盘定位、选择中心点、锁定、复位、重画。
- 工具只展示默认、激活、禁用状态，不承担真实画布操作。
- 操作参考浮窗采用 DW 运营毛玻璃，可拖动至画布外的视口区域，并支持多示例切换。
- 关闭参考浮窗后用 Tooltip 提示右侧教程按钮可重新打开。
- 辅助线密度使用单个滑动条，默认“密”。

#### 明确不实现

- 真实画框、选点、拖拽、缩放、鼠标辅助坐标、角度计算和量程联动。
- 表单校验、完成检查、量程段增删或选中切换。
- 保存模板数据或调用后端。

## 5. 响应式与滚动验收

- 1440×800：主页面结构、固定顶栏、分页、表格和弹窗完整可见。
- 1440×520：页面本体不出现纵向滚动；任务、列表、建议或工具内容在指定区域内滚动。
- 窄屏：表格最右操作列可通过同一横向滚动容器访问，表头与内容列不脱节。
- 所有按钮文本、标签、标题不截断或重叠；按钮组间距保持 8px。

## 6. 研发验收清单

- 推理卡片可进入详情，详情返回推理首页。
- 上传异常图片自动清理并显示处理结果；不弹重复确认。
- 质量报告显示六轴雷达、标注质量双子指标和直接行动。
- 首次分析类型选择自动显示教程，关闭后出现一次入口提示。
- 两个训练入口复用同一套训前自检规则。
- AI 预警阻塞训练；仅提醒可继续；暂不可评估引导标注。
- 训练完成后可进入部署状态；成功和失败弹窗路径均可演示。
- 验证失败可查看漏检图片。
- 指针模板四步指引仅切换静态状态，不产生真实几何数据。
- 类型检查、生产构建和单文件构建全部通过。
